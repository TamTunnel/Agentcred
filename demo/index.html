AgentCred

A verifiable transaction passport for AI agents — no card numbers, no PKI, no backend in this demo.

github.com/TamTunnel/agentcred

1 · Agent

Holds a mandate chain from its owner: you may spend up to $100 on purchases. For one checkout it mints a passport — merchant-scoped, 15-minute, signed.

2 · Passport

A canonical JSON envelope: the signed mandate chain, a canonical spend scope, and a sha256 binding the two. Pseudonymous DIDs only — no PII.

3 · Merchant

Verifies signatures, the chain, the aud binding, expiry, scope narrowing and replay — then approves. No agent blocklist, no card.

Try it — live, in your browser

Keys are generated with WebCrypto and never leave this page. The "merchant" below is just JavaScript + localStorage standing in for the file-backed replay store.

What the merchant checks

    
    
      
  1. Canonical encoding — the envelope must be byte-equal to its canonical form; reordered keys or extra whitespace are rejected.
    2. 
      
  2. Leaf binding — leaf_sha256 must match the mandate; the scope can't be transplanted onto another signature.
    3. 
      
  3. Merchant (aud) binding — the passport is minted for one merchant id; anyone else rejects it.
    4. 
      
  4. Signatures — Ed25519 did:key at every link, strict base64url throughout.
    5. 
      
  5. Scope confinement — each link may only narrow: amount ≤ every ancestor's limit, child expiry ≤ parent expiry.
    6. 
      
  6. Revocation — leaf and ancestor JTIs are checked against the issuer's signed revocation list.
    7. 
      
  7. Replay — the leaf JTI is consumed in a persistent store (here: localStorage; in production: a file-backed cache that survives restarts).
